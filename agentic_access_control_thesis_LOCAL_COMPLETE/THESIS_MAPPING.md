# Mapping the implementation to the thesis

| Thesis concept | Implementation artifact |
|---|---|
| Synthetic SaaS environment | `environment.py`, `data/cases.json` |
| Deterministic detection held constant | `detector.py`, `data/detector_validation.json` |
| A1 detection-only | `ExperimentRunner.run_one()` A1 branch |
| A2 human-approved remediation | `ExperimentRunner.run_one()` A2 branch + `human_review.py` |
| A3 bounded autonomy | `ExperimentRunner.run_one()` A3 branch + `guardrails.py` |
| Context/evidence collection | `tools.py` |
| Agent recommendation | `reasoners.py` |
| Action allowlist and policy-action mapping | `config/actions.yaml` |
| Action-impact gating | `config/actions.yaml`, `guardrails.py` |
| Valid-exception check | `environment.py`, `guardrails.py` |
| Simulated human review | `human_review.py` |
| Auditability | `audit.jsonl` generated by `experiment.py` |
| TTR, RSR, HIR, IRR, CS | `experiment.py`, `evaluation.py`, `summary.json` |
